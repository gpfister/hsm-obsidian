# HW-084 DS3231 Real-Time Clock Module

The **HW-084** is an ultra-precise Real-Time Clock (RTC) expansion breakout based on the **Maxim Integrated DS3231SN** chip. In the air-gapped Raspberry Pi HSM OS ([`hsm-yocto-offgrid-rpi`](file:///Users/gpfister/Development/Projects/gpfister/nrf52840-hsm/hsm-yocto-offgrid-rpi)), it serves as the physical hardware timekeeping reference for the cryptographic appliance, ensuring accurate UTC timestamps for certificate generation, RAUC dual-slot updates, audit logs, and PKCS#11 tokens without external network connectivity.

---

## 1. Hardware Specifications & Chip Architecture

| Feature | Specification |
| :--- | :--- |
| **Manufacturer / Model** | HW-084 Breakout / Maxim Integrated DS3231SN |
| **Clock Source** | Internal 32.768 kHz Temperature-Compensated Crystal Oscillator (TCXO) |
| **Accuracy** | ±2 ppm from 0°C to +40°C (approx. ±1 minute per year) |
| **Communication Bus** | I2C Fast Mode (up to 400 kHz), standard 100 kHz operational mode |
| **I2C Slave Address** | `0x68` (7-bit, standard I2C address) |
| **Operating Voltage** | 2.3V to 5.5V DC (operates at 3.3V DC on Raspberry Pi GPIO) |
| **Backup Battery** | CR2032 3V Lithium Coin Cell (or rechargeable LIR2032 with charge circuit) |
| **Battery Life** | > 5 years continuous timekeeping under power loss (typ. 1.0 µA standby current) |
| **Integrated Sensors** | Internal digital temperature sensor (±3°C accuracy) |
| **Form Factor** | Compact 40mm × 20mm breakout module with 2.54mm pin header |

## 2. Electrical Interconnect & Raspberry Pi Pin Mapping

The HW-084 module connects to the primary hardware I2C bus (**I2C-1**) on the Raspberry Pi 40-pin header. In the physical appliance, it connects via female jumper wires to the GPIO passthrough pins of the [[Hardware/Waveshare USB HAT (B) Integration|Waveshare USB HAT (B)]].

## 3. Battery Circuit & Charging Caution

> [!CAUTION]
> Many commercially available HW-084 / ZS-042 breakout modules include a simple diode-and-resistor trickle-charging circuit designed for rechargeable **LIR2032** coin cells. If a standard non-rechargeable **CR2032** lithium manganese dioxide coin cell is used, the continuous trickle voltage will degrade or damage the battery.
> 
> **Standard Practice for Air-Gapped Appliances**:
> 1. Use standard non-rechargeable **CR2032** batteries for long shelf-life (>5 years).
> 2. Disable or desolder the charging diode (or 200Ω SMD resistor labeled `201`) on the breakout board to eliminate battery charging current completely.

## 4. Software Stack & Driver Architecture

1. **Broadcom Hardware Controller**: The SoC Broadcom BCM2835 hardware I2C controller operates I2C-1 at 100 kHz (`CONFIG_I2C_BCM2835=y`).
2. **Firmware Device Tree Overlay**: `/boot/config.txt` loads `dtoverlay=i2c-rtc,ds3231` and enables `dtparam=i2c_arm=on`.
3. **Linux Kernel Driver**: The upstream `rtc-ds1307` driver (`CONFIG_RTC_DRV_DS1307=y`) binds to device address `0x68`, initializing `/dev/rtc0`.
4. **Early Boot Clock Recovery**: Kernel `CONFIG_RTC_HCTOSYS=y` initializes `CLOCK_REALTIME` from `/dev/rtc0` at kernel startup.
5. **User Space Interface**: Accessible via `hwclock` and setuid root helper `/usr/local/bin/hsm-set-date` using `ioctl(RTC_SET_TIME)`.
